## Задача 1.1

**Моделирование дискретного источника** · [`source.py`](source.py)

### Генерация последовательности

```sh
python3.11 source.py generate examples/source14.json --N 20 --seed 14
```

`generate` выводит по одному JSON-символу на строку. При `--N None`, $N\le 0$ или без `--N` генерация продолжается до **Ctrl+C**

### Вероятность и частотная оценка

```sh
python3.11 source.py estimate examples/source14.json --N 1000000 --word examples/word.json --seed 14
```

`estimate` принимает блок как JSON-массив строк и требует $N\ge r>0$, где $r$ означает длину блока

| Поле | Результат |
| --- | --- |
| `first` | Точная вероятность первого блока |
| `average` | Среднее вероятностей первых $L$ стартовых позиций |
| `frequency` | Частота блока в реализации длины $N$ |
| `table` | Частоты и отклонения для $N\in\{10^2,10^3,\ldots,10^6\}$ и заданного $N$ |

## Задача 1.2

**Равномерное кодирование источника без памяти** · [`coding.py`](coding.py)

```sh
python3.11 coding.py entropy examples/iid14.json
python3.11 coding.py code examples/iid14.json --R 1.6
```

Оба режима проверяют стационарность и отсутствие памяти

| Режим | Результат |
| --- | --- |
| `entropy` | Энтропия $H$ в битах на символ |
| `code` | Точные ошибки, минимальное $n$ на заданном отрезке и ответ о существовании $n_0$ для всех достаточно больших $n$ |

> **Параметры по умолчанию:** `q=5`, `epsilon=1/10000`, `nmax=50`

Ключи `--q`, `--epsilon`, `--nmax` и `--output` задают мощность алфавита кодера, границу ошибки, максимальную длину блока и путь файла кода

В [code14.json](code14.json) сохраняется описание кодов для всех рассмотренных $n$. Формат описан в [отчёте](REPORT.md#файл-кода)

## Задача 1.3

**Архиватор Хаффмана** · [`huffman.py`](huffman.py)

```sh
python3.11 huffman.py compress examples/files/russian.txt --stats
python3.11 huffman.py decompress examples/files/russian.txt.zmh --output russian.restored
```

`compress` добавляет к имени файла расширение `.zmh`. `decompress` восстанавливает исходные байты и проверяет CRC32. Ключ `--output` задаёт путь результата, без него при восстановлении удаляется последнее расширение

Для результата требуется свободное имя файла. Неполный результат при ошибке удаляется

| Поле `--stats` | Значение |
| --- | --- |
| `H` | Эмпирическая энтропия в битах на байт |
| `average_length` | Средняя длина кода одного исходного байта в битах |
| `header_bytes`, `data_bytes` | Размеры заголовка и потока кодов в байтах |
| `input_bytes`, `archive_bytes` | Размеры исходного файла и архива |
| `ratio` | Отношение исходного размера к полному размеру архива |

Формат `.zmh` и измерения приведены в [отчёте](REPORT.md#задача-13), пять файлов для проверки находятся в [examples/files](examples/files/)

## Навигация по коду

| Файл | Основные функции |
| --- | --- |
| [source.py](source.py) | `parse_source` читает модель, `generate` выдаёт символы, `probability` считает вероятность блока, `estimate` измеряет частоту |
| [coding.py](coding.py) | `iid_distribution` проверяет источник, `entropy` считает энтропию, `error_table` выбирает наиболее вероятные блоки, `eventual` проверяет условие для больших $n$ |
| [huffman.py](huffman.py) | `code_lengths` строит дерево, `canonical_codes` восстанавливает коды по длинам, `compress` упаковывает биты, `decompress` восстанавливает файл |

В каждом модуле `main` обрабатывает параметры запуска и сообщения об ошибках. Проверки находятся в [tests](tests/)
