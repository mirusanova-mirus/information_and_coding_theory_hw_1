## Задача 1.1

**Моделирование дискретного источника** · [`source.py`](source.py)

### Генерация последовательности

```sh
python3.11 source.py generate examples/source14.json --N 20 --seed 14
```

`generate` выводит по одному JSON-символу на строку. При `--N None`, $N\le 0$ или без `--N` генерация продолжается до **Ctrl+C**

### Вероятность и частотная оценка

```sh
python3.11 source.py estimate examples/source14.json --N 1000000 --word examples/word.json --seed 14
```

`estimate` принимает блок как JSON-массив строк и требует $N\ge r>0$, где $r$ означает длину блока

| Поле | Результат |
| --- | --- |
| `first` | Точная вероятность первого блока |
| `average` | Среднее вероятностей первых $L$ стартовых позиций |
| `frequency` | Частота блока в реализации длины $N$ |
| `table` | Частоты и отклонения для $N\in\{10^2,10^3,\ldots,10^6\}$ и заданного $N$ |

## Задача 1.2

**Равномерное кодирование источника без памяти** · [`coding.py`](coding.py)

```sh
python3.11 coding.py entropy examples/iid14.json
python3.11 coding.py code examples/iid14.json --R 1.6
```

Оба режима проверяют стационарность и отсутствие памяти

| Режим | Результат |
| --- | --- |
| `entropy` | Энтропия $H$ в битах на символ |
| `code` | Точные ошибки, минимальное $n$ на заданном отрезке и ответ о существовании $n_0$ для всех достаточно больших $n$ |

> **Параметры по умолчанию:** `q=5`, `epsilon=1/10000`, `nmax=50`

В [code14.json](code14.json) сохраняется описание кодов для всех рассмотренных $n$. Формат описан в [отчёте](REPORT.md#файл-кода)
