# Формат источника, вариант 14

[Главная](README.md) · [Отчёт](REPORT.md) · [Результаты проверок](RESULTS.md)

## Грамматика

Обязательные поля **`models`**, **`switches`**, **`source`** сохраняются. Необязательное поле `process` имеет вид

```json
{
  "initial": {"left": "1/2", "right": "1/2"},
  "states": {
    "left": {"switch": "left", "next": {"A": "left", "B": "left", "C": "left"}},
    "right": {"switch": "right", "next": {"A": "right", "B": "right", "C": "right"}}
  }
}
```

| Поле | Назначение |
| --- | --- |
| `initial` | Распределение начального состояния |
| `states` | Состояния источника |
| `switch` | Имя переключателя текущего состояния |
| `next` | Следующее состояние для каждого символа алфавита |

Алфавит объединяет символы всех моделей. Полный пример: [nonergodic14.json](examples/nonergodic14.json)

**Правила проверки**

- Имена и символы являются непустыми строками
- Вероятности задаются строками с дробями или десятичными числами, пропущенные координаты равны 0
- Распределения непустые, неотрицательные и имеют сумму 1
- Все ссылки должны существовать, список `source` должен быть непустым

## Семантика

### Исходный формат

Без `process` на такте $t$ используется переключатель из `source` с позицией $t\bmod L$: переключатель выбирает модель, модель выбирает символ. Такты независимы

Исходный формат представляется циклом состояний $0,\ldots,L-1$. Начальное состояние равно 0, переключатель состояния $j$ равен `source[j]`, переход всегда ведёт в $(j+1)\bmod L$. Старые файлы принимаются без изменений

### Расширенный формат

Начальное состояние выбирается по `initial`. На каждом такте

1. Переключатель текущего состояния выбирает модель
2. Модель выдаёт символ $a$
3. Состояние меняется на `next[a]`

Длина `source` задаёт $L$ для усреднения, сами переключатели определяются состояниями

Источник памяти $d$ задаётся состояниями из последних $d$ символов и сдвигом контекста после выхода. Произвольные условные распределения выражаются переключателями над тремя точечными моделями, четвёртая модель сохраняет $M=4$

## Примеры

Примеры в [examples](examples/) имеют $k=3$, $M=4$, $L=7$

| Модель | $P(A)$ | $P(B)$ | $P(C)$ |
| --- | ---: | ---: | ---: |
| $m_1$ | $\frac{1}{2}$ | $\frac{1}{3}$ | $\frac{1}{6}$ |
| $m_2$ | $\frac{1}{3}$ | $\frac{1}{3}$ | $\frac{1}{3}$ |
| $m_3$ | $\frac{1}{6}$ | $\frac{1}{3}$ | $\frac{1}{2}$ |
| $m_4$ | $\frac{3}{4}$ | $\frac{1}{8}$ | $\frac{1}{8}$ |

### Стационарный источник

[iid14.json](examples/iid14.json): все позиции выбирают $m_1$, символы независимы и одинаково распределены

### Нестационарный источник

[source14.json](examples/source14.json): чередуются $P=(\frac{5}{12},\frac{1}{3},\frac{1}{4})$ и $R=(\frac{5}{9},\frac{7}{36},\frac{1}{4})$ по схеме $P,R,P,P,R,R,P$, поэтому распределение зависит от номера такта

### Эргодический источник

[markov14.json](examples/markov14.json): 27 контекстов $(x,y,z)$ с равномерной начальной мерой, выбор $m_1$, $m_2$ или $m_3$ зависит от $x$, после выхода $a$ контекст становится $(y,z,a)$

Матрица трёх распределений дважды стохастическая, поэтому начальная мера инвариантна. Положительность переходов и петля AAA обеспечивают неприводимость и апериодичность. Зависимость от самой старой буквы даёт память ровно $d=3$

### Неэргодический стационарный источник

[nonergodic14.json](examples/nonergodic14.json): с вероятностями $\frac{1}{2}$ выбираются поглощающие состояния `left` с $m_1$ и `right` с $m_3$. Смесь стационарна, но инвариантное событие «предельная частота A равна $\frac{1}{2}$» имеет вероятность $\frac{1}{2}$

> В исходном формате стационарность требует одинаковых распределений во всех фазах. При независимых тактах это iid-источник, который эргодичен. Сохраняемое случайное состояние в расширении позволяет задать стационарную неэргодическую смесь
