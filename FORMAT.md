# Расширение формата

## Грамматика

Обязательные поля `models`, `switches`, `source` сохраняются. Необязательное поле `process` имеет вид

```json
{
  "initial": {"left": "1/2", "right": "1/2"},
  "states": {
    "left": {"switch": "left", "next": {"A": "left", "B": "left", "C": "left"}},
    "right": {"switch": "right", "next": {"A": "right", "B": "right", "C": "right"}}
  }
}
```

`initial` - распределение начального состояния, `states` - состояния с именем переключателя `switch` и переходами `next` для всех символов алфавита. Алфавит объединяет символы моделей. Полный файл примера - `examples/nonergodic14.json`

Имена и символы - непустые строки. Вероятности - строки с дробями или десятичными числами, пропущенные координаты равны 0. Распределения непустые, неотрицательные и имеют сумму 1. Все ссылки должны существовать, `source` должен быть непустым

## Семантика

Без `process` на такте t используется `source[t mod L]`: переключатель выбирает модель, модель выбирает символ. Такты независимы

С `process` начальное состояние выбирается по `initial`. На каждом такте переключатель текущего состояния выбирает модель, модель выдаёт символ a, затем состояние меняется на `next[a]`. Длина `source` задаёт L для усреднения, сами переключатели определяются состояниями

Исходный формат - частный случай: состояния 0,...,L-1, начальное состояние 0, переключатель состояния j равен source[j], переход всегда в (j+1) mod L. Старые файлы принимаются без изменений

Источник памяти d задаётся состояниями из последних d символов и сдвигом контекста после выхода. Произвольные условные распределения выражаются переключателями над тремя точечными моделями, четвёртая модель сохраняет M=4

## Примеры

Примеры источников в `examples/` имеют k=3, M=4, L=7. Модели: m1=(1/2,1/3,1/6), m2=(1/3,1/3,1/3), m3=(1/6,1/3,1/2), m4=(3/4,1/8,1/8)

- Стационарный `iid14.json`: все позиции выбирают m1, символы независимы и одинаково распределены
- Нестационарный `source14.json`: чередуются P=(5/12,1/3,1/4) и R=(5/9,7/36,1/4) по схеме P,R,P,P,R,R,P, поэтому распределение зависит от номера такта
- Эргодический `markov14.json`: 27 контекстов xyz с равномерной начальной мерой, выбор m1, m2 или m3 зависит от x, после выхода a контекст становится yza. Матрица трёх распределений дважды стохастическая, поэтому начальная мера инвариантна. Положительность переходов и петля AAA обеспечивают неприводимость и апериодичность. Зависимость от самой старой буквы даёт память ровно d=3
- Неэргодический стационарный `nonergodic14.json`: с вероятностями 1/2 выбираются поглощающие состояния left с m1 и right с m3. Смесь стационарна, но инвариантное событие «предельная частота A равна 1/2» имеет вероятность 1/2

В исходном формате стационарность требует одинаковых распределений во всех фазах. При независимых тактах это iid-источник, который эргодичен. Сохраняемое случайное состояние в расширении позволяет задать стационарную неэргодическую смесь
